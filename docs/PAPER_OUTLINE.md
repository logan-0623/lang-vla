# 论文大纲（草稿，2026-10-24）

## 暂定题目（2026-10-24 按近邻修正）

- *When the Object Name Hurts: Stage-Dependent Effects of Object Identity in Language-Conditioned VLA Control*
- *The Object Word Helps Before the Grasp and Hurts After It*（前提是 D 组和阶段对照能支持这个说法）

## 一句话主张（修正版）

在冻结的 StarVLA-OFT 上：物体被正确抓稳以后，指令里具体的物体名会妨碍机器人执行原定的目的地；把物体身份抽象掉（`it` / `the object`）就能恢复大部分放置。抓取之前，物体名却是选对物体所必需的。我们用同状态分叉研究这种作用如何随阶段变化，并划出它的边界。

**不再主张：** 用代词修复是一种新方法（Learning What to Say v2 附录已经把 `it` 列为候选）；"名词触发熟悉操作"是新发现（PerturBot）；"指令检索轨迹"是新发现（2609.39971）。检索式解释只作为竞争假设之一。

## 贡献（修正版）

1. **同状态分叉协议：** 把抓取前选物体和抓取后放置拆开，在同一个物理状态上比较语言和查询的干预（方法工具，非新颖性中心）。
2. **抓稳以后，指令查询能改变目的地的分布**（T1、T2，有配对统计）。说"能改变"，不说"完全决定"：T1 也有不达门槛的格子。
3. **物体身份的作用随阶段改变（中心贡献，待 D 组和阶段对照补全）：**
   - 抓稳后把物体抽象掉，成功率 9/60 → 33–34/60，救回 25、丢失 1（W1）。
   - 回合一开始就把物体抽象掉，机器人按目的地键去拿默认物体（k5：19/20 拿了碗），事后观察。
   - D 组检验抽象之后机器人是否仍然跟随目的地词。
4. **边界：** 在冻结的留出组合上，"炉前"这种训练里没有放置示范的目的地，即使抓稳并换成 it 也是 0/20（Z2）。这与"依赖已见技能"相容，但不能唯一证明检索机制。
5. **负结果：** 低秩"概念子空间"修补不比同等修补量的随机方向更好（R1、T3、配对统计）。

## 必须对比的近邻

- **Learning What to Say（2606.12299v2）：** 我们不需要交互搜索和学习的反馈策略，用的是一条固定规则。增量在于把"抓稳后物体身份"这个效应单独隔离出来，并测量它的阶段依赖。注明我们的触发条件用的是仿真里的抓取真值。
- **TLI 的换指令基线（2505.03500v5 §4.2）：** 和"抓稳事件触发的已见指令切换"（instr-A）做公平比较，并注明这是对其思路的适配，不是原论文的复现。
- **PerturBot：** 他们是名词保留、动词改变；我们是物体名抽象、目的地保留，而且看它与抓取阶段的交互。
- **InstructMove：** 按它的原则补 D 组，即换掉物体词以后，目的地仍然可以由语言选择。
