特定措辞仍会在抓取后改变去向

最初每任务仅 1 条来源改写；扩展到 3 条后，抓起后的失败仍集中在碗任务和部分措辞，不能推广到所有改写。

无意义目标词实验 H3′观察预先写定规则的判定
OFT抓起碗后，blicket / dax 与空指令的结果分布相同，TV = 0.00；倾向灶台。支持
VLA-Adapter既有去柜顶的倾向，也有继续原任务的情况；默认去向与轨迹惯性混合。未满足全部预测

碗抓起后仍能改道，但窗口会随执行进度关闭

确定的行为差异

碗在抓取后仍有可观察的改道窗口。酒瓶在较早的 E4 批次中，抓取前 20 步切换的新目标执行率就已为 0。

按 H1″ 的预设阈值：VLA-Adapter 支持；OFT 未达到全部预测，但未触发反证。

机制解释仍待检验

可能取决于任务从哪里开始分叉

碗的多个去向可以共享抓取动作；酒瓶的不同去向可能需要不同抓法。“先开抽屉再放碗”也更早失去改道能力。

这提示动作兼容性和数据分歧可能重要，尚未建立因果关系。

一次重要的实验修正：原 H1′ 使用固定的“抓起后 +20 步”，部分任务此时已接近完成，两个模型均触发反证。保留原判定，再用独立写定的 H1″ 改为按进度取样；两批场景不同，不能逐条配对。

来源：[1] E4、H1′ 有效性核查、H1″。* 酒瓶 q = 75% 的原指令重启成功率也只有 55–57%，该点不能单独说明语言不起作用；q = 25% 的原指令基线为 95–100%。

发现三 · 低成本测量与数据效应
05 / 08

初始观测上的动作变化，可以预测改写后的失败

在相同观测上比较原句、改写和其他任务的动作输出。R_action 用“换成其他任务”的动作差异归一化改写造成的动作差异。

E6 与 LIBERO-Para 对齐，每模型 3,889 条改写；AUC 衡量对失败的排序能力。
预测指标VLA-AdapterOFT
1 − 句子结构相似度0.5730.496
1 − 关键词相似度0.7590.769
R_action0.798 [0.785, 0.812]0.866 [0.854, 0.877]

用途：快速筛查语言脆弱性

R_action 从最低五分位升至最高五分位时：

VLA-Adapter 的成功率84.5% → 14.1%
OFT 的成功率93.6% → 14.5%

指标只需固定观测上的前向对比，不需要为每条新改写另跑完整轨迹。

同结构模型也会因数据范围而变化

OFT 从 Goal 单套训练改成四 suite 联合训练：

物体词改写 R_action0.297 → 0.454
空指令 R_action1.003 → 1.494

动作对文本更敏感，不等于语义理解更好。该比值的归一化分母也可能随训练变化。

当前 AUC 来自同类初始观测，LIBERO-Para 每条改写只有一次 rollout。仍需对关键词基线做配对差异检验，并验证跨状态的预测能力；不能把 AUC 直接解释成语言理解或因果使用的证据。

来源：[1] E6、E6 → LIBERO-Para、2026-10-17 补充核查。置信区间沿用原结果记录，未在本汇报中重新估计。

从观察到研究问题

用语言表达的空间与物理知识，能否迁移到动作？

目前的文本实验建立了行为现象；新的主线检验哪些上游能力能改善有限示范下的机器人泛化。

上游学习
VLM + 空间状态问答

由仿真真值提供位置、关系、持物与设施状态等监督。

→
下游迁移
相同 Goal 示范训练 VLA

固定骨干、动作头、机器人数据与评测方式。

→
闭环检验
已见任务 + 新组合目标

观察成功率、样本效率，以及上游能力是否保留。

目前准备到哪里

已完成4 个模型的新目标基线；StarVLA 接入与分叉复现验证。
已采集空间问答 v1：训练集 2,480 张图、留出集 592 张图；按场景划分。
待核查坐标约定已确定为只翻转列；修正后的数据重建与留出集标签抽查仍需确认。
待结果当前材料尚未记录 A/B/C/D 的完整训练与迁移评测结果。

现有计划的主要对照

分支VLM 上游阶段
A不增加问答训练
B自然语言空间问答
C同图像上的非空间问答
D与 B 相同的事实，以 JSON 表达

D 检验文本表达形式；JSON 也是文本。C 的答案对图像依赖较弱，对额外视觉监督的控制仍有限。混合问答训练 A+co / B+co 作为后续分支。

进一步的工作假设

语言对“动作前提与物理后果”的监督，可能形成更容易迁移的表征。例如，同一状态执行不同动作后，物体是否被抓住、是否失去支撑。v1 主要是静态空间与状态问答，尚未验证这一假设。

来源：[2] §11 与待验证清单；[4] 用户提供的问答采集输出。语言的作用是研究假设，“文本是智能根本”不作为本轮实验已证明的结论。

汇报收束 · 下一步与讨论
08 / 08

下一步建立“学会、保留、用上”的证据链

学会

上游能力是否提升？

比较原始 VLM 与问答训练后的留出场景准确率。先确认训练确实获得了目标能力。

保留

VLA 微调后是否还在？

再次测同类问答，区分上游没有学会和微调后能力下降。必要时检验混合训练。

用上

闭环行为是否改善？

在相同机器人数据下测新目标成功率，并确认已见任务没有明显退化。

近期优先项

  1. 确认 n5 / n6 / n8 的可行性，以及 QA 修正后的标签质量。
  2. 推进固定配置下的 A/B/C 对比，D 检验表达形式；主判定比较补充训练种子。
  3. 评测 OFT 四 suite 联合版，进一步约束数据覆盖的解释；仍需控制训练配方等差异。

当前结论的范围

  • 早期 E3–E6 主要为探索性结果；H1″、H3′、N0 保留预先写定规则的原判定。
  • 行为失败尚不能证明上游知识被“学崩”，需要微调前后的测量。
  • 问答提升、前向动作变化和闭环收益是不同层次的证据。
希望与导师讨论：优先检验静态空间知识的迁移，还是在第一轮结果后扩展到动作前提与后果？论文的核心应落在“哪些知识可迁移、怎样迁移”的可验证规律上。
