Literature brief · VLA language grounding

Do VLAs read the instruction?

Five recent LIBERO studies say mostly no. High success rates come from mapping the scene to a memorized trajectory, not from following the language.

Evidence

LIBERO-PRO2510.03827
Swap objects, corrupt the instruction, replace it with random tokens.

Models still grasp the old target. Trajectories barely change, even with garbled text.

LIBERO-ParaKim et al., 2603.28301
Paraphrase the instruction. Vary verbs and object names separately.

Object synonyms cause most of the loss. Models match surface words, not meaning.

One underlying cause

H(instruction | image) ≈ 0  ⇒  I(action ; instruction | image) ≈ 0

When the scene already determines the task, the instruction carries no extra information. Imitation learning then has no reason to use it.

Formalized as “information collapse” in LangForce (2601.15197).

What this means for our evaluation

  • LIBERO-Spatial and Object success does not show language understanding.
  • Test on shared-scene suites: LIBERO-Goal, LangGap, LIBERO-CF.
  • Report a language-reliance index: SR(correct) − SR(other task's instruction).
Numbers are each paper's headline result. Models, suites and protocols differ, so rows are not directly comparable.
